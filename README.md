# מחולל תעודות 🎓

ממשק להפקת תעודות סיום מקובץ אקסל, לפי התבנית של בית הספר הרב תחומי.

**האתר:** https://amal-ramot.github.io/teudot/

## איך משתמשים
1. **העלאת נתונים** – גוררים קובץ אקסל (‎.xlsx / ‎.xls / ‎.csv). אם יש כמה גיליונות – הנתונים מכל הגיליונות מאוחדים לרשימה אחת (אפשר לבטל גיליון), ותלמיד שמופיע בכמה גיליונות מתמזג לפי ת"ז.
2. **התאמת עמודות** – לכל שדה בתבנית («שם פרטי», «שם משפחה», «ת"ז», «כיתה», «מקבילה», «מגמה», «מחנך») בוחרים עמודה מהאקסל. יש התאמה אוטומטית לפי שם, ואפשר גם לקבוע ערך קבוע.
3. **עיצוב ומיקום** – עורך חזותי: גוררים רכיבים, משנים גודל, גופן, צבע ויישור; מוסיפים טקסט, חתימות ותמונות, מחליפים רקע. כל שדה שנכתב בתוך «» הופך לשדה מיזוג. אפשר לשמור/לטעון את התבנית כקובץ JSON.
4. **ייצוא** – PDF אחד לכל התעודות או ZIP עם PDF נפרד לכל תלמיד, ב־3 רמות איכות (עד 300dpi).

הכל רץ בדפדפן – הנתונים לא נשלחים לשום שרת.

## פיתוח
```bash
npm install
npm run dev
```
